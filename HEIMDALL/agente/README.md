# Agente

Scripts operacionais do HEIMDALL.

Ordem de uso:

1. `check-firewall-passwords.bat`: valida host, porta e senha.
2. `install-pfsense-restapi.bat`: instala o pacote REST compatavel com a versao detectada.
3. `configure-fleet-guardian-api.bat`: padroniza a configuracao da API e cria chave.
4. `install-fleet-guardian-agent.bat`: instala o agente seguro para Direct View e backup.

Execute primeiro em poucos dispositivos de laboratorio antes de aplicar em lote.
